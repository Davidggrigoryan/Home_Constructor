# Home Constructor

Прототип веб-портала для людей, которые планируют построить собственный дом. Решение включает две ключевые функции:

- **Калькулятор стоимости строительства.** Пользователь выбирает площадь, количество этажей, материал стен, уровень отделки и дополнительные опции. Скрипт рассчитывает ориентировочную стоимость проекта.
- **Конструктор помещений.** Посетители добавляют комнаты с заданными размерами, получают суммарную площадь и видят визуальную сетку помещений.

## Структура

- `public/index.html` — разметка страницы с двумя модулями.
- `public/styles.css` — минималистичный стиль с акцентами и адаптивной сеткой.
- `public/app.js` — логика калькулятора и конструктора помещений.

Для просмотра достаточно открыть `public/index.html` в браузере.
